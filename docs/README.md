# Geometric Lib

## Общее описание решения

**Geometric Lib** — это библиотека на Python для вычисления площадей и периметров различных геометрических фигур.
Библиотека состоит из отдельных модулей, каждый из которых отвечает за определённую фигуру:

- `circle.py` - вычисления для круга
- `square.py` - вычисления для квадрата
- `rectangle.py` - вычисления для прямоугольника
- `triangle.py` - вычисления для треугольника

Каждый модуль содержит функции `area()` и `perimeter()`, которые принимают целые числа (int) и возвращают результат в виде целого числа.

---

## Описание функций с примерами вызова

### Модуль `circle.py`

#### **Функция:** `area(r)`
Вычисляет площадь круга.

**Аргументы:**

- `r (int)` - радиус круга.

**Возвращает:**
- `int` - площадь круга.

**Пример вызова:**

```python
area(3)
28
```

#### **Функция:** `perimeter(r)`
Вычисляет длину окружности.

**Аргументы:**

- `r (int)` - радиус круга.

**Возвращает:**
- `int` - длина окружности.

**Пример вызова:**

```python
perimeter(3)
18
```

### Модуль `square.py`
#### **Функция:** `area(a)`
Вычисляет площадь квадрата.

**Аргументы:**

- `a (int)` - сторона квадрата.

**Возвращает:**
- `int` - площадь квадрата.

**Пример вызова:**

```python
area(4)
16
```

#### **Функция:** `perimeter(a)`
Вычисляет периметр квадрата.

**Аргументы:**

- `a (int)` - сторона квадрата.

**Возвращает:**
- `int` - периметр квадрата.

**Пример вызова:**

```python
perimeter(4)
16
```

### Модуль `rectangle.py`

#### **Функция:** `area(a, b)`
Вычисляет площадь прямоугольника.

**Аргументы:**

- `a (int)` - длина прямоугольника.
- `b (int)` - ширина прямоугольника.

**Возвращает:**
- `int` - площадь прямоугольника.

**Пример вызова:**

```python
area(3, 4)
12
```

#### **Функция:** `perimeter(a, b)`
Вычисляет периметр прямоугольника.

**Аргументы:**

- `a (int)` - длина прямоугольника.
- `b (int)` - ширина прямоугольника.

**Возвращает:**
- `int` - периметр прямоугольника.

**Пример вызова:**

```python
perimeter(3, 4)
14
```

### Модуль `triangle.py`

#### **Функция:** `area(a, h)`
Вычисляет площадь треугольника по основанию и высоте.

**Аргументы:**

- `a (int)` - основание треугольника.
- `h (int)` - высота, проведённая к основанию.

**Возвращает:**
- `int` — площадь треугольника.

**Пример вызова:**

```python
area(4, 6)
12
```

#### **Функция:** `perimeter(a, b, c)`
Вычисляет периметр треугольника.

**Аргументы:**

- `a (int)` - первая сторона.
- `b (int)` - вторая сторона.
- `c (int)` - третья сторона.

**Возвращает:**
- `int` - периметр треугольника.

**Пример вызова:**

```python
perimeter(3, 4, 5)
12
```
